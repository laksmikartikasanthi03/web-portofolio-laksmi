## 🚀 Fitur Interaktif Unggulan

1. **Spotlight Cursor Card Physics**:
   * Efek pencahayaan kartu reaktif mengikuti posisi kursor secara halus (*hardware-accelerated*) menggunakan CSS variables `--mouse-x` dan `--mouse-y`.
2. **Command Palette (`Ctrl+K` / `⌘K`)**:
   * Akses cepat keyboard-driven untuk navigasi instan antar seksi, tautan eksternal, dan aksi penyalinan email.
3. **Interactive Developer Terminal (Sandbox REPL)**:
   * Konsol shell virtual interaktif yang disesuaikan untuk Laksmi:
     * `help` — Menampilkan panduan perintah.
     * `whoami` — Profil ringkas Laksmi Kartika.
     * `about` — Filosofi desain antarmuka berbasis data & logika matematika.
     * `skills` — Rincian keahlian Data, Desain UI/UX, dan Logika Komputasi.
     * `projects` — Daftar karya Project Base & Case Based Learning.
     * `certs` — Riwayat sertifikasi profesional & kepemimpinan organisasi.
     * `contact` — Saluran kontak resmi.
     * `clear` — Membersihkan console.
4. **Modal Spesifikasi Sistem & Dokumen Terintegrasi**:
   * Setiap proyek dilengkapi modal penjelasan teknis mendalam dan tombol akses langsung ke dokumen resmi/PDF (Jurnal Riset Keamanan Siber, Skema Database Kampus, dan Laporan Rancang Bangun CRM).
5. **Image Lightbox Zoom**:
   * Klik pada foto profil atau sertifikat apa pun untuk menampilkan pratinjau resolusi tinggi dalam modal lightbox yang elegan.
6. **Live WITA Clock**:
   * Jam sistem tersinkronisasi otomatis dengan zona waktu Waktu Indonesia Tengah (WITA / UTC+8).
7. **One-Click Email Copy & Toast Notification**:
   * Salin email resmi dengan satu klik disertai feedback visual *toast alert*.
